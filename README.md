# Gym-Store

## 🚀 Overview  
Gym-Store is a modern web application built using Python and Streamlit. It’s designed to showcase a clean, interactive storefront interface for a gym equipment store — enabling users to browse products, view details, and enjoy a streamlined UX experience.

## 🧩 Features  
- Interactive product catalog with thumbnails and product details  
- Responsive UI built with Streamlit’s layout components  
- Easy-to-navigate pages: Home, Product Details, Checkout (if applicable)  
- Modular code structure for maintainability and future enhancement  
- Use of static assets (images, icons) stored in `assets/` directory  
- Clean file structure:  
  - `pages/` – separate Streamlit pages  
  - `Home.py` – main landing page  
  - `assets/` – images, icons  
  - `README.md` – project documentation
